# Internal link map (SplitHaus guides)

Rule set (approved structure 2026-10-01):
- Every post links in its body text to at least 2 other published posts, in a sentence where the reader would naturally want that next step. Descriptive link text (the topic), never "click here" or "learn more".
- Every post in a topic links up to that topic's main guide. Main guides link down to their supporting posts once those are published.
- Every post links to /playbook once (the conversion step).
- Never link to an unpublished post: the live blog returns 404 for drafts. Add links on the day a post publishes, and add the reverse links in older posts that same day.
- Related-guides cards (3, same topic first) sit at the end of every article; the hub links to every published post.
